# 🖨️ 印刷ステーション

児童がPDFを送る → 先生が一覧から **1タップ／まとめて印刷**。
**アカウント登録なしで児童が使えて、先生はどの端末（iPad等）からでも操作**できる、先生のための印刷アプリです。

- 児童：送信ページで「ねん・くみ・ばん」を選んでPDFを送るだけ
- 先生：先生ページ（パスワードで保護）で確認して印刷
- 印刷は**その端末に登録済みのプリンタ（AirPrintなど）**で行うので、特定のパソコンに縛られません

---

## 👩‍🏫 先生へ：自分専用の印刷ステーションを作る（約5分）

**あなた専用のアプリ**ができます。あなたの児童のデータは**あなたの場所だけ**に入り、他の人には見えません。

### 手順

1. 下のボタンを押します

   [![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/33rrr33/print-station)

2. **Render**（無料）に登録／ログインします
3. 設置画面で **`TEACHER_PASSWORD`** に、**あなただけが分かるパスワード**を入力します
4. **Apply（設置）** を押すと、数分であなた専用のURL（`https://〇〇.onrender.com`）ができます
5. 先生ページ `〇〇.onrender.com/teacher` を開く → パスワードを聞かれるので入力（**ユーザー名は空でOK**）
6. その画面に出る **「👦 児童用リンク」** をコピーして、児童に配ってください

これで完成です。児童がPDFを送ると、あなたの先生ページに並びます。

### 使い方

- 児童：配られたリンクを開く → ねん・くみ・ばん → PDFを選ぶ → そうしん
- 先生：一覧で「印刷（ひらく）」→ 端末のプリントで自分のプリンタへ／「まとめて印刷」で選んだPDFを1回で

---

## 🔒 安全・プライバシーについて

- 先生ページ・PDFの閲覧は**パスワードで保護**（`TEACHER_PASSWORD`）。**パスワード未設定の間は先生ページは停止**し、児童のデータは誰にも表示されません
- 児童の送信ページは鍵なしで送れますが、**中身は先生しか見られません**
- **各先生のデータは、その先生のアプリの中だけ**にあります。配布者や他の先生は一切見られません
- 無料プランは、しばらくアクセスが無いと一時停止し、預かり中のPDFは消えます（印刷まちは一時的なものなので運用上は問題ありません）

## 💻 開発者向け（ローカル実行）

```bash
pip install -r requirements.txt
TEACHER_PASSWORD=あなたのパスワード python app.py
```

`http://localhost:8000/`（児童用）／`http://localhost:8000/teacher`（先生用）

構成：`app.py`（本体・標準ライブラリ＋pypdf）／`requirements.txt`／`render.yaml`
