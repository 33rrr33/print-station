# 🖨️ 印刷ステーション（Print Station）

校内LANだけで完結する、**アカウント不要**のPDF印刷システムです。
児童がPDFを送る → 先生が一覧を見て **1タップ／一括で印刷**、という流れを、
先生の負担なく実現します。標準ライブラリ（Python3）だけで動きます。

## 仕組み

```
児童（iPad等） → 送信ページでPDFを送る
        ↓ 自動
先生のMac    → 「印刷ボックス」フォルダに保存され、先生用コンソールに並ぶ
        ↓
先生         → 部数を確認して「印刷」／「チェックを印刷」をタップ
        ↓
プリンタ     → 紙が出る（印刷後は「印刷ずみ」フォルダへ自動で移動）
```

## 主な機能

- 児童用の送信ページ（ねん・くみ・ばんを選ぶだけ、ひらがな表記）
- 先生用コンソール（`/teacher`）
  - 届いたPDFの一覧・中身プレビュー
  - 部数の増減ボタン（初期1部）
  - チェックボックスで選んで **一括印刷**
  - 不要なPDFの削除（「印刷ずみ」フォルダへ退避＝復元可能）
  - 児童用リンクの発行（コピーして配布）
- プリンタは自動選択（アプリ側で機種名を扱いません）
- 外部サービス・インターネット送信は一切なし。校内で完結

## 使い方

```bash
python3 print_station.py
```

起動すると、ターミナルに **児童用URL** と **先生用URL**（`/teacher`）が表示されます。
同じ校内Wi-Fiの端末からそのURLを開いてください。
PDFはデスクトップに自動作成される `印刷ボックス` フォルダに入ります。

## 必要な環境

- macOS（`lp` コマンドで印刷）
- Python 3
- Mac に印刷したいプリンタが追加済みで、同じネットワークに接続されていること

## 注意

これは **各自のMacで動かすローカルアプリ** です。
GitHub Pages などの静的ホスティングでは動きません
（自分のMacのプリンタとフォルダにアクセスして動くため）。
他の先生が使う場合も、そのMacでこのプログラムを起動してください。
