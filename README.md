# 🖨️ 印刷ステーション（どこでも版）

**1つのURL**を、iPad・iPhone・PC どの端末で開いても使える、**アカウント不要**のPDF印刷システムです。
印刷は「その端末のプリント画面」で行うので、**その端末に登録済みのプリンタ（AirPrintなど）**にそのまま出せます。
特定のパソコンやプリンタに縛られません。

## 仕組み

```
児童（iPad等） → 児童用リンクで ねん・くみ・ばん を選び、PDFを送信
        ↓
サーバー      → PDFを一時保管し、先生ページに並べる
        ↓
先生（iPad等） → 一覧をタップ → 端末のプリント画面 → 自分のプリンタで印刷
```

- **印刷はブラウザ（端末）側**が実行。サーバーはPDFを預かって並べるだけ
- 「まとめて印刷」＝選んだPDFを1つに合体して開く → **プリント操作1回**で全部印刷

## 主な機能

- 児童用の送信ページ（`/`）… ねん・くみ・ばんを選ぶだけ・ひらがな表記
- 先生用コンソール（`/teacher`）
  - 児童用リンクの表示＋📋コピー（そのまま配れる）
  - 届いたPDFの一覧・プレビュー
  - 「印刷（ひらく）」→ 端末のプリントで自分のプリンタへ
  - チェックで選んで「まとめて印刷」（合体PDFを1回で印刷）
  - 不要なPDFの削除

## デプロイ（Render）

このリポジトリには `render.yaml` が入っています。

1. [Render](https://render.com) にログイン
2. **New → Blueprint** を選び、このリポジトリ（`print-station`）を指定
3. 自動で `pip install -r requirements.txt` → `python app.py` が実行され、公開URLが発行される
4. そのURLを先生ページ（`/teacher`）で開くと、児童用リンクが自動表示される

Renderの無料プランは一定時間アクセスが無いとスリープし、保管中のPDFは消えます
（印刷まちは一時的なものなので運用上は問題ありません）。

## ローカルで動かす

```bash
pip install -r requirements.txt
python app.py
```

`http://localhost:8000/`（児童用）／`http://localhost:8000/teacher`（先生用）

## 構成

- `app.py` … サーバー本体（標準ライブラリ＋PDF結合に pypdf）
- `requirements.txt` … 依存（pypdf）
- `render.yaml` … Render 設定

## 🔒 パスワード保護（重要）

先生ページ（`/teacher`）と、届いたPDFの閲覧・一覧・結合は**パスワードで保護**されます。
児童の送信ページ（`/`）は誰でも送れますが、**中身は先生しか見られません**。

- 環境変数 `TEACHER_PASSWORD` にパスワードを設定してください（コードには書きません）
- **未設定のあいだ、先生ページは安全のため停止**します（児童のデータは誰にも表示されません）
- Renderの場合：ダッシュボード → 対象サービス → **Environment** → `TEACHER_PASSWORD` に値を設定 → 保存
- 先生ページを開くとパスワードを聞かれます（ユーザー名は空でOK、パスワードだけ入力）
